## The agent activity spec — owner-approved, 2026-11-22

The spec every agent is judged against. An agent is done only when its
activities below run in production, on the ledger and metered, inside
its gates. The full file is kept in the tester's workspace.

**Legend.** E: an employee. A: an agent alone. A→E: an agent prepares,
a person decides.

**Standing gates, never delegated to an agent.** Moving money. Signing.
Decisions about a person. Publishing compliance copy.

| Area | Agent alone (A) | Agent prepares, a person decides (A→E) | A person (E) |
|---|---|---|---|
| 1. Win work | Digest scanner: requirement digests into deduplicated requirement records. Census keeper: the customer and supplier census, active against dormant. Confirmation tracker: submissions out against confirmations in; blocks a dual authorization; a draft is not a confirmation; a bounce reopens as failed delivery. | Drafts of outreach and chases. | Rate and chase decisions, and outreach. |
| 2. Fill it | Match ranker: bench and candidates ranked against a requirement. | Consent before submission. Submission, and the chase on interview movement. | Interviews. The offer (rate, start date, terms), which needs an Offer record. |
| 3. Start them | Contracts checklist: agreed against actual on the MSA, SOW and PO, with drift flags. Immigration checklist: one checklist per petition, with each paper its own line. | The onboarding pack complete before day one. The placement record (customer, end client as the worksite, rate, supplier chain): a person confirms what the agent assembled. | Signatures, routed to the signatory. |
| 4. Run the week | Chase agent: missing-timesheet chases per consultant per period; an arrival on any thread closes its chase. Payroll draft from approved weeks. | | Week approval. Payroll release. |
| 5. Money loop | The invoice from the signed week. Chase and reconciliation: payments matched to invoices; short pays and rate drift flagged. | Invoice sends, and chasing money owed with evidence. A final notice and a payroll hold stay behind a person. | The second approver on exceptions. Paying suppliers and consultants, by maker and checker. Collections escalation, with the agent keeping the evidence. |
| 6. Keep it legal | Compliance watch: tenure limits per consultant per client. The ledger: every action recorded by itself, and the ledger is also the billing meter. | Labor-condition notices posted on time, up ten business days, their removal logged. | 7. Run the firm | The weekly census and payroll-hours summary. The agent control view: running, actions, meter. | | The decision queue, oldest first with proof, cleared daily. The kill switch. Hiring and firing, pricing, binding the firm. |

**The acceptance rule.** Every activity either feeds the decision queue
or closes a loop on the ledger. An activity that does neither is not
built. Agents own chasing, matching, reconciling and remembering.
People own deciding, signing, paying and people.

**Where it meets standing text (the lead's reading; nothing built).**
1. *An agent alone that chases.* The email law of the same day (record
   110) says agents draft and people approve, and the pack (record 105)
   says no agent sends anything. The lead reads "chase agent, alone" as:
   the agent owns the chase's record, its timing, its draft and its
   closing, and a person's yes still sends it, until the owner says an
   agent may send. He should say which.
2. *The digest scanner* meets "Etyme never reads a mailbox". It waits on
   his ruling on the door, as before.
3. *The match ranker* needs the model switched on for the tenant, and
   its key, which the owner pastes.
4. *The Offer record* does not exist. It is new building.
5. *A payroll hold as a lever* still waits on regulatory's reading.
6. *What exists today toward this:* the ledger with its three stamps,
   the decision queue, the agent control view with six agents reading
   "Not enabled", the month from timesheet to payment, and the mail
   ledger. No agent runs.
