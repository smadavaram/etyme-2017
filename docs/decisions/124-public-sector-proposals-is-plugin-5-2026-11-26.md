# 124 — Public-sector proposal creation is plugin 5 — 2026-11-26

**Ruled by the tester (BA and architect), under record 123.**

Creating government and public-sector proposals is plugin 5. It has its
own dedicated agent and is switched on per tenant, on the same switch as
the other plugins (record 120). It is not a large-enterprise tier.

## Price

- Switching it on is free.
- Each agent action is metered on the ledger.
- Heavy solving work is consulting at $200 an hour.

## What the agent does

The agent drafts, assembles, and chases missing pieces from the tenant's
own record: its bench, compliance, rates and past performance. A person
approves and submits, always. The agent never submits a proposal.

## Order

It queues after plugins 1 to 4, and no build starts on it before them.
If a government deadline falls before it ships, the work is delivered as
consulting, on the record.

## Amended, 2026-11-26 (record 126)

"Switching it on is free" now reads: switching it on follows the tenant's edition, so a paying enterprise tenant switches modules on as a paid tenant. The plugin ruling itself stands.
