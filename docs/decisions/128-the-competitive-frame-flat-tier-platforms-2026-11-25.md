# 128 — The competitive frame: flat-tier platforms — 2026-11-25

**The owner's direction, relayed by the tester, Nov 25.** The owner named a
competitor and asked to beat its class quickly.

The standing rule (CLAUDE.md, "What Etyme is") keeps every real company's
name out of pages, records, tests, code and commits. So this record names
the competitor by its class only. Its name may appear in one place: as a
label on the import setting, where a customer picks the system it is
leaving.

## The competitor class

These are platforms that serve one staffing firm in a closed silo. They
sell flat monthly tiers, published at about $98 to $5,100 a month, and
each tier has hard limits:
- the number of active placements;
- the size of the resume database;
- the AI credits.

## Where Etyme wins

1. **No price jumps.** A firm that outgrows a placement limit must jump to
   the next tier, which costs about twice as much. Etyme charges $20 per
   active contractor, a steady price at every size (record 127).
2. **One shared record.** A supplier and its clients work on the same
   record. Access as a user inside a client's record is free, at every
   level of the network (record 126).
3. **Government contractors.** The competitor class wins government
   contractors on audit and task-order credibility. Plugin 5, the proposal
   agent working from the tenant's own record (record 124), and the audit
   ledger go after that same group.

## To build

**An importer from the competitor's exports**, queued after the plugin
switch build. It maps consultants, clients, placements, timesheets and
invoices into the Etyme record, using the census-import machinery that
already exists. A migration is delivered as consulting at $200 an hour.

## The switch offer

This is framing only, and nothing is sent. Sixty days free lets a firm run
Etyme alongside its current system for one full cycle. It cancels the old
system only once Etyme has proved itself. Firms stay because switching is
risky, not because of price.

## The sales gate still binds

There is no outreach until Tapin and the second firm have each passed two
weekly cycles and one invoice cycle. "Quickly" means everything is ready
when the gate passes: the target list, the importer and the switch offer.
The campaign then fires in the first week after the gate. The gate is
never skipped.
