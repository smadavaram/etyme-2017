Screen designs for the Base44 build

Bench and inbox

Two dashboards, one for each side. Both are built around the same idea: an ordinary staffing tool shows you records. These show you work moving through a loop.

The strip across the top of each screen is the loop itself, with live counts at every stage and the fix-branch drawn in. A recruiter can see in one glance what is stuck, what is being repaired, and what is waiting on a human — which is exactly what no ATS shows today.

Notes for whoever builds this

Eight things that are easy to get wrong and expensive to fix later.

The loop strip is not decoration

Each node is a count() over one status value on the Submission record. Building it forces the status machine to be right, which is why it goes in first, not last.

Draw the fix branch even when it is empty

Showing "0 being fixed" tells the user the check ran and everything passed. Hiding it makes a working loop look like no loop at all.

The top-left number is the money

Vendor: idle bench days. Client: stalled roles. Both are costs, both are top-left, both stay there. Never replace them with something more flattering.

Sort by the painful thing

Bench sorts by most idle. Requirements sort by most stalled. Vendors sort by placement rate, never by volume. The default sort is the product's opinion.

Never show a score without its proof

Every score in these tables opens to the quoted lines from the CV behind it. A number on its own is what every ATS already does badly.

"Needs a person" is a real panel

Escalations, expiring permits, and the check queue are work, not notifications. Give them a panel with a count, not a bell icon nobody clicks.

Build the empty state first

A new vendor has no bench and no requirements. That screen is their whole first impression, and it should say what to do next in three lines.

Two themes, one token set

Every colour here is a CSS variable redefined for dark mode. Violet is the supply side, teal the demand side, orange means act, green pass, red fail. Nothing else gets a colour.
