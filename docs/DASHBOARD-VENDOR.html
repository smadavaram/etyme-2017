Notes for whoever builds this

Six things specific to this screen.

Idle days lead, and stay leading

Sorted most idle first, with a bar that runs red past about forty days. This is the number the owner already worries about at night.

Skip is a real button

Recorded, not just ignored. Skipping the wrong requirements is a thing you want to measure once outcomes come back.

Consultant freshness sits on the main screen

Unconfirmed people are downweighted in scoring. If that state is buried in a settings page, nobody fixes it and the bench quietly rots.

"Needs a person" is a panel, not a bell

Escalations after three fix attempts, expiring permits, rate overrides. These are work items with a count, not notifications.

Show cost per submission weekly

It is how you catch someone removing the rules filter to "improve accuracy" and quintupling the bill.

Rules-based checks are marked free

Rate, documents and dates cost nothing and are right every time. Showing that keeps the team reaching for code before the model.
